Your agent shouldn’t read that.

A PDF can carry instructions no person will ever see: white text, half-point type, words painted under a box, a note in a hidden annotation. An agent’s PDF loader reads all of them, and the model acts on them.

Parallax compares what the loader extracts with what Foxit’s render of the page actually shows, and hands the agent only what a person could read.

Two views of the same page

A hidden instruction is, by definition, text that exists in the file and not on the page. So Parallax asks for both, from Foxit PDF Services, and compares them.

  1. Read it like a loader

    The text layer, as agent frameworks extract it: Foxit pdf-to-text, plus pypdf and pdf.js, the libraries behind LangChain’s loaders. Annotations, form values and metadata are read too.

  2. Look at it like a person

    Foxit renders every page to an image with pdf-to-image, rebuilds it from pixels with pdf-from-image and reads it back with pdf-ocr. What comes out is what a reader can see.

  3. Keep what both agree on

    Text in the first view and not the second is flagged. Foxit’s pdf-structural-analysis explains it where it can, a 0.5 pt font or a box off the page, and supplies the structured elements the agent receives instead.

Sixteen documents, twelve with something hidden

Invoices, terms, an NDA, CVs, a purchase order. Each attack uses a different way of hiding text. The four controls are there to catch false alarms: a legitimate 6 pt footnote, white text on a navy band that anyone can read, a scan with no text layer at all, and a plain clean invoice.

The proposal

Foxit’s MCP server and agentic workflow guides put PDFs in front of agents. Nobody has yet written about what a PDF can do to the agent reading it. This is that piece, and it is the natural sequel to Foxit’s own API World challenge, Your Agent Shouldn’t Sign That.

It also sits next to the security work already in Foxit’s products. PDF Action Inspector finds active code a person cannot see. Parallax finds instructions a person cannot see, using nothing but Foxit PDF Services to do it.

What to know about these numbers

  • Every attack here was written by hand for this test. The corpus is small and single-page on purpose, so each result can be read and checked; it is not a measure of how often these attacks occur.
  • Parallax finds text that is in the file and not on the page. It does not judge text a person can see but might skim past, and it does not decide whether flagged text is malicious. It reports what it found and why, and leaves it out of what the agent receives.
  • The comparison assumes the loader and the OCR read in roughly the same order. Complex multi-column layouts can misalign and are the first thing to harden.
  • A one-page document costs five Foxit credits: text, render, rebuild, OCR and structure. Each further page adds two.
