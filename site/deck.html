A content proposal for the Foxit developer program

Your agent shouldn’t read that.

Parallax finds instructions hidden in PDFs before an agent acts on them, using nothing but Foxit PDF Services.

Egor, first place in Foxit’s challenge at API World 2026

Agents read text that people never see

White text, half-point type, words under a box, text off the page, notes in hidden annotations. None of it shows on screen or in print. All of it reaches the model as ordinary text.

Foxit’s MCP server and agentic workflow guides are putting PDFs in front of agents. Nobody has written yet about what a PDF can do to the agent reading it.

Two views of the same page, both from Foxit

  1. Read it like a loader

    The text layer as agent frameworks extract it, plus annotations, form values and metadata.

    pdf-to-text

  2. Look at it like a person

    Every page rendered to pixels, rebuilt as a PDF and read back by OCR. What comes out is what a reader can see.

    pdf-to-image pdf-from-image pdf-ocr

  3. Keep what both agree on

    Text in the first view and not the second is flagged and explained. The agent receives only the structured elements the page confirms.

    pdf-structural-analysis

Five Foxit PDF Services endpoints, end to end. Five credits for a one-page document.

Why this belongs on the Foxit developer blog

  • It is the sequel to Foxit’s own challenge

    Your Agent Shouldn’t Sign That asked where an agent’s authority should stop. This asks what an agent should be allowed to read.

  • It fills a gap next to the MCP server

    Setup guides and agentic workflow articles exist. A guide to keeping those agents safe from the documents they ingest does not.

  • It extends a story Foxit already tells

    PDF Action Inspector finds active code a person cannot see. Parallax finds instructions a person cannot see.

  • It is a showcase for PDF Services

    Rendering, OCR, structural analysis and conversion, working together to answer a question none of them answers alone.

The proposal

Sample app
Parallax, hardened and documented, as an open-source repository developers can run on their own documents.
Article
About 1,500 words for the Foxit developer blog walking through the code.
Benchmark
The corpus and scoring script, public, so the numbers can be checked and the attacks extended.
Timeline
Sample app and benchmark in week one after scope is agreed, article in week two.
Could follow
A tamper-evident audit trail for AI document decisions; an agent toolkit for the Vercel AI SDK and OpenAI Agents SDK with eSign behind human approval.
